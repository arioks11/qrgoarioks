    Exports never include Wi-Fi passwords. Other fields (names, phone numbers, addresses) are included, so treat the file as personal data.

    Help / FAQ

    Pick a type, fill the fields, adjust the look, then download PNG or SVG. Always test-scan a printed code. Use error correction H with a logo and keep strong contrast. Dynamic (editable) QR codes need a server and are not available in this static version.

    Privacy

    QR codes, logos and CSV files are processed locally and never uploaded. History is stored in this browser's localStorage only and does not sync between devices. This page bundles its QR and ZIP libraries, so no third-party requests are made. No analytics are used.
